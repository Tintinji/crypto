# 逻辑链（多空必须按节对打）

禁止两边各写互不交手的研报。节标题必须原样使用。每一节至少引用 `00-facts.md` 里的一个数字；facts 写「未知」则该节必须把不可验证性本身写成论点。

## 链 A — 原生 L1 / L2 / 应用 / 交易所 / meme / 隐私币

1. 这个资产在卖什么，谁付钱？
2. 需求是在扩张还是叙事空转？
3. 代币如何捕获价值？
4. 供给何时变差？
5. 竞争替代成本是什么？
6. 估值锚是否过大？
7. 未来 12 个月必须发生 / 绝不能发生的事

## 链 B — 稳定币

1. 储备 / 抵押与历史脱锚
2. 分发、结算场景、份额变化
3. 发行主体与监管
4. 收益与激励是否在买份额
5. 链上渗透 vs 对手
6. 挤兑与传染路径

## 链 C — 包装资产 / LST / LRT

1. 对底层的映射：托管、合约、赎回
2. 流动性与脱锚
3. 收益来源是否可持续
4. 中心化与监管
5. 相对原生资产的折溢价是否给够风险补偿

## 链 D — RWA / 代币化基金 / 黄金 / 信贷份额

1. 法律请求权与链上代币分别代表什么？
2. 底层资产、净值计算、审计/托管是否可验证？
3. 谁是买家（理财替代、抵押品、通道）？份额是否在扩张？
4. 流动性、二级市场深度、相对 NAV 的折溢价
5. 监管、合格投资者、赎回门槛
6. 信用 / 利率 / 运营失败时的损失路径
