## 第 1 轮：各攻对方最弱三点

### 多方攻空方

1. **用价格路径与「无 OI」把已核对费用写成空转。** 空方把距 ATH `$89.60` 仅 `-12.39%`、30d `+33.50%`（相对 `+12.66%`）、1y `+46.10%`（相对 `+124.08%`）写成不能当份额扩张，再把 OI 未知读成需求不可见。可核验的是协议家族费用 30d `$81.10M`、1y 与年化均为 `$926.80M`，Llama type=revenue 同步 `$81.10M` / `$926.80M`。价格路径证明二级报价，不能单独把这两笔写成用量归零。7d `-7.30%`（相对 `-4.73%`）与 BTC 7d `-2.70%` 同向，是短窗回吐，不是费用表停转。24h `+2.05%` 对 BTC `+0.57%`，相对值本包未给，不得自算。24h 成交额 `$911.47M`、成交额/MC `5.22%` 是换手：空方用它否定份额扩张可以，但不能用换手当「费用已空」。稳定币流通与 OI 未知，空方不得把未知补成流失。

2. **「必须按 UNI `6.31x` / AAVE `2.42x` 给 `$75.02B` 定价」错把对照锚当充分条件。** 双方已承认 HYPE 不是借贷公用事业，也不是 fee switch 未开的 DEX 治理币。空方一面排除 AAVE 公用事业桶，一面用 `2.42x` 与 UNI `6.31x` 证明约 81x 过大，等于把增长永续改回已当股权定价。赛道读法：个位数是已当股权，50–100x 是增长永续；`80.94x` 落在该档，前提是费用真实且收入对齐。UNI 年化 `$915.8M` 与本币同级，但赛道写明 fee switch 长期未完全打开——协议有费用 ≠ 代币有收入。AAVE 年化 `$774.4M`、MC/TVL `0.10x` 与 MORPHO / SKY 同列 0.10–0.26x，尺子不能套到永续。链费用年化 `$11.21M` 不是主账单，空方不得改按一层 gas 给 FDV 定价。

3. **「看不见日历=未流通已变差」把缺口写成冲击。** 公开接口未提供已验证解锁日历，不得编造解锁美元。可观察面：流通 `222.45M`、总供给 `955.31M`、硬顶 `1.00B`，MC/FDV `0.23`，流通市值只反映约四分之一供给。赛道点名未流通是空方主攻，不等于已经发生的抛压。未知日历是约束，不是已落地的稀释冲击。24h `+2.05%` 没有表现为独立于 BTC 的供给折价。

### 空方攻多方

1. **「收入与费用同数=代币已捕获 / 不是 UNI 漏出」超证。** 多方用 Llama revenue 与费用同为 `$926.80M` 压过「费用漏出代币」。facts 未给销毁、回购或质押分成，持有人看不见可分配票息。赛道第一节要求点名费用留在协议还是留在代币：账本对齐不等于收费权已交给持币人。FDV/年化费用 `80.94x` 是在薄浮筹上标的增长倍数，不是股权票息。日成交 `$911.47M` 不是票息。CEX 托管 AUM 未知，不得当协议收入。

2. **「`80.94x` 落在 50–100x=锚不大 / `#11` 即护城河」循环。** 多方用赛道增长档解释 `$75.02B`。`80.94x` 远高于 UNI `6.31x`、AAVE `2.42x`；已流通 `$17.47B` 约是 UNI `$4.04B` 的四倍，费用几乎同级（约 `$0.92B`）。30d 费用 UNI `$182.6M` 高于本币 `$81.10M`，近期费率并不支持把同级年化费用标到 FDV `$75.02B` 对 `$5.78B`。MC/TVL `2.55x` 对 UNI `1.12x`、AAVE `0.10x`，分母还含桥 `$6.50B`。赛道合计 `$54.7B`，本币独占 `$17.5B`，不能自证倍数合理。距 ATH `-12.39%`，约 81x 没有被压缩。

3. **「费用机器 + `$6.85B` TVL=需求扩张 / 搬迁成本极高」缺仓位与迁出额。** 1y `+46.10%`、30d `+33.50%` 是价格路径，不是未平仓量。协议家族 TVL `$6.85B` 中桥 `$6.50B`、HLP `$187.42M`、现货订单簿 `$160.06M`；链上 DeFi TVL `$1.30B` 不是 MC/TVL 主锚。本包无 OI，稳定币流通未知，禁止把未知补成份额扩张。赛道写明永续份额从 CEX 搬到 HYPE / ASTER / LIT，同时这些平台自己也在发币补贴。多方「`$926.80M` + `$6.85B` + `#11` 即搬迁成本」缺迁出序列，不能把桥写成不可迁移库存。

## 第 2 轮：六点标 承认 / 反驳 / 降级

1. **价格路径 / 无 OI=费用空转或份额扩张：反驳双向超证，并降级空方措辞。** 空方须把「不能当份额扩张」降级为「费用真实且大，OI 与份额不可见」。多方同时承认：`$81.10M` / `$926.80M` 只证明协议费用与收入未消失，不证明永续份额在扩张；1y `+46.10%` / 相对 `+124.08%`、30d `+33.50%` 双方承认是价格路径，不是仓位。7d `-7.30%` 可逆，不能写成费用表停转。空方亦不得把距 ATH `-12.39%` 写成费用已空。OI 与稳定币流通未知，双方不得补成流失或扩张。

2. **80.94x 对 6.31x/2.42x=增长档或不贵 / 必须收到股权倍数：承认落在 50–100x 带，降级错尺与循环。** 双方承认按赛道读法 `80.94x` 落在「增长永续」档，且远高于 UNI `6.31x`、AAVE `2.42x`。空方「必须按 `6.31x` / `2.42x` 给 `$75.02B` 定价」降级为错锚条件——双方已声明不卖 UNI 现货开关、也不卖 AAVE 公用事业。多方「落在 50–100x 故锚不大 / `#11` 撑住分子」降级为循环：增长档是读法，不是已核实便宜。30d UNI `$182.6M` 高于本币 `$81.10M` 只证明近期费率对照，不能单独把年化同级改写成已贵或已便宜。不得改按链费用年化 `$11.21M` 给 FDV 定价。

3. **收入=费用=代币捕获 / 账本≠票息：承认双方都缺分配路径。** 双方承认 Llama revenue 与费用同数，协议账本对齐；facts 未给销毁、回购或质押分成。多方「不是 UNI 那种费用漏出」降级为「收入已入账，持币人收费权未列路径」；空方「看不见票息即捕获失败」降级为「分配路径未知，不是费用为零」。UNI 对照成立的是同级费用与未完全打开的 fee switch，不能把 HYPE 读成无收入治理币，也不能把账本对齐读成已分红。

4. **30d / 日量 / 近 ATH=需求扩张：承认多方超证。** 多方承认 `$911.47M` / `5.22%` 是换手，30d `+33.50%`（相对 `+12.66%`）可逆，不能覆盖也不能改写已核对年化 `$926.80M`。7d `-7.30%` 与 BTC 同向，24h `+2.05%` 相对值未给，不是独立需求脉冲。距 ATH `-12.39%` 不是安全垫。空方降级：不能因短窗与近高点主张 `$926.80M` 已失效。

5. **换永续 DEX / 回 CEX=已被替代：降级。** 双方承认拥挤点：份额从 CEX 搬到 HYPE / ASTER / LIT，平台同时发币补贴。空方「换一家即可」缺 OI 与迁出额，降级为「替代成本下降，搬迁额写不出来」。多方「`$926.80M` + `$6.85B` + `#11` 即搬迁成本」同样缺序列，降级为存量费用与位次，不是不可替代证明。桥 `$6.50B` 不得写成不可迁移库存。AAVE / MORPHO / SKY 的 0.10–0.26x 不得并入永续倍数表。

6. **0.23=折价安全或供给已变差：承认结构缺口，双方都缺日历。** 双方承认解锁日历未知，不得编造到期美元。流通 `222.45M`、总供给 `955.31M`、硬顶 `1.00B`、MC/FDV `0.23` 只标出浮筹缺口：MC `$17.47B` 给已流通定价，FDV `$75.02B` 把未流通一并计入 `80.94x` 分母。多方「未知解锁不是已落地稀释」降级为仅排除已编造的悬崖，不能把 `0.23` 补成供给安全；空方「看不见日历即供给变差」降级为数据缺口。`$926.80M` 能否对冲未流通进入不可核验。ATL `$3.81` 只作历史下沿。
