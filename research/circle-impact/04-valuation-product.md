**投票前 $97 附近定价了三层，而不是一层「USDC 合法」：**

1. **核心特许权（仍在）：** GENIUS 下的支付稳定币发行人 + 储备利息引擎 + 已落地的支付/机构分销。对应大致是 **200 日均线一带（~$86）或更低的「基金+网络」底**。Yahoo 前瞻 ~53x、FY26 共识 ~76x 说明市场本来就把 Circle 当成长股，不是 10x 银行。
2. **2026 年内市场结构成文法期权（已被抽走）：** 银行合规备忘录、美国现货场所联邦路径、对「平台奖励 vs 社区存款」的事前规则。Polymarket 投票前「2026 年市场结构成法」已只有约 **17%**（总览备忘录）；9/14 的 $97 是把残值又买了一遍标题。
3. **银行级分销 / 奖励战场的「规则书红利」（被减记，未归零）：** 部分卖方把 CLARITY 误读成「禁止稳定币付息、从而拉平 Circle vs Coinbase」。**发行人「仅因持有而付息」早已被 GENIUS 禁止**；CLARITY 争的是 **平台/第三方奖励** 与存款外流监视。Circle 自己不向持有人付息，靠 Coinbase 等分销分成。法案失败 = **CEX 奖励赛道继续灰色运行**，Circle 分销成本与「合规美元」溢价都没有被立法锁定。

**被抽走的政策期权价值（判断，不是回归）：**

- 相对 9/14：$97 → $81，约 **$16 / 股，约 −17%**。
- 相对 9/3 政策高点 $103：约 **−22%**。
- 相对 200 日均线 $86：现价大约 **平或略折价**——即「法案周溢价」已基本吐完，**尚未打到 50 日 $76 的更干净基本面底**。
- 用稀释股数 ~2.69 亿，**$16/股 ≈ 市值 $43 亿**。这更像 **久期与倍数压缩**，不是把 $74B USDC 的法定地位折成零。

**没有被抽走的：** USDC 赎回权、GENIUS 实施日历、OCC 国民信托牌（Circle National Trust，Q2 已获最终批准）、NYDFS 信托、法籍 EMI + CASP、CPN / Managed Payments / Arc。

交叉引用：总览备忘录已写「股票卖的是增长期权 / 银行分销 / 市场结构溢价」。本路用价格路径把这段溢价量化到 **大约一至两成市值、对应 200 日均线以上的法案周加价**。

## 3. 长端特许权：GENIUS 2027 牌照 + 2028 DASP 墙 vs USDT / 银行币 / PYUSD

CLARITY 管的是 **现货市场结构**。Circle 的十年特许权管线是 **GENIUS**，投票没有改日期。

| 闸门 | 日期 | 对 Circle | 对对手 |
|---|---|---|---|
| GENIUS 生效（发行人） | **不晚于 2027-01-18**，或联邦主监管终稿后 120 天（取较早者） | 必须是 **PPSI**；Circle 已有 OCC **国民信托** + NY 信托，路径最干净之一 | 未获许可的离岸发行人不能在美新发 |
| 分销墙（DASP） | **2028-07-18**（颁布满 3 年） | 美国交易所/钱包原则上只能向美国人提供 **PPSI 或被认定同等的外资** 稳定币 | **USDT 主币**若无财政部同等性认定 + 注册，从美国零售货架退出；**USAT** 必须自己长成 |
| 发行人付息禁令 | 已在 GENIUS | Circle 模式本来就不付持有人利息 | 不保护 CEX 平台奖励；那是 OCC / 银行游说下一战场（见银行备忘录） |

### 3.1 对 Tether：2028 墙比 2026 法案更致命

- **USDT** 流通约 **$1,832 亿**（Etherscan/CMC，9 月中）。交易 TAM、离岸、Tron 零售的霸主。**不是** MiCA EMT，欧盟持牌所已限制对 EEA 客户的 USDT 现货对。
- **USA₮ / USAT**（Anchorage Digital Bank 发行、GENIUS 通道）：流通仅约 **$1.85–1.90 亿**。品牌在，规模是 USDC 的 **~1/400**。Tether 用双币策略保住离岸 USDT，用 USAT 占美国合规格；**目前没有证据表明 USAT 能在 18 个月内替代 USDC 的机构/支付流动性。**
- 2028-07 之后：美国 DASP 货架大概率变成 **USDC + 银行币 + PYUSD + USAT + 少数同等外资**。USDT 可以继续统治离岸永续，但 **「美国合规美元」份额** 是 Circle 的结构性期权——**不依赖 CLARITY**。

### 3.2 对银行币：真正的长端对手，也不靠 CLARITY

JPM Coin / JPMD、Citi Token Services、BNY 链上存款镜像、TCH 跨行网络（目标约 2027）走的是 **可付息银行负债**。GENIUS 禁止的是 **支付稳定币发行人** 对持有人付息，不是银行存款付息。CLARITY 失败 **没有削弱银行币**，反而让「存款外流事前禁令」没有入法，银行在奖励战场战术赢、产品战场继续铺。

对 Circle 的含义：2027–28 特许权不是「没有对手的垄断」，而是 **「合规、可赎回、多链、已嵌入 Stripe/Shopify/SAP」的公开美元** vs **「付息、封闭、银行客户」的存款代币**。前者吃跨境与链上；后者吃国内批发与托管客户。CLARITY 本来可能让部分银行更敢分销 **公开稳定币**；现在它们更可能把预算留给 **自家币**。

### 3.3 对 PYUSD / PayPal

- 供给从 2026-03 高点约 **$42 亿** 回落到年中约 **$27–28 亿**（激励退坡）。相对 USDC 仍是小数。
- PYPL 9/14–16 仅约 −2%：市场不认为这次投票改变 PayPal 主业，也不认为 PYUSD 突然吃掉 USDC。
- SAP Digital Currency Hub **预置 USDC 与 PYUSD**（以太坊 / Polygon）。企业财务软件层是 **双币**，不是 Circle 独占；但深度流动性与跨链仍在 USDC。
- PayPal 的优势是 **4 亿级账户分销**；劣势是供给弹性与链上深度。没有 CLARITY，两边都继续靠 GENIUS，而不是靠新的市场结构法互相封锁。

### 3.4 2027–28 特许权判断（研究权重）

| 情景 | 权重 | CRCL 特许权 |
|---|---|---|
| 基准：GENIUS 如期实施，USDT 主币 2028 退出美国 DASP，USAT 缓慢爬坡，银行币切走批发付息余额 | ~50% | USDC 保持「美国合规美元」第一；供给 CAGR 低于公司口头 40%，但支付 + 机构仍能支撑「网络」叙事 |
| 偏牛：OCC 收紧平台奖励 + USAT 起不来 + CPN/Arc 把其他收入做实 | ~25% | 倍数可以从「纯基金」回到「基金+网络」；与 CLARITY 无直接关系 |
| 偏熊：2027 国会换手削弱 GENIUS 实施 / 银行币 + 通证化现金替代储备外余额 / 供给跌破 $60B | ~25% | 特许权变成高 β 货币市场基金，FY27 58x 站不住 |

**结论：** 长端故事的硬日期是 **2027-01-18 与 2028-07-18**，不是 2026-09-15。CLARITY 失败把 **美国银行分销的可选加速** 拿掉，没有把特许权墙拆掉。

## 4. 支付 TAM vs 交易 TAM：没有 CLARITY，哪条故事还活着

| 故事 | 是否依赖 CLARITY | 投票后 | 证据 |
|---|---|---|---|
| **支付 / 结算 TAM**（Stripe、Shopify、SAP、CPN、银行出入口） | **否（GENIUS + 牌照）** | **继续** | 见下 |
| **交易 / CEX 奖励 TAM**（Coinbase 等对平台内 USDC 发 3.5–4.5% APY，Circle 付分销费） | **部分依赖** 市场结构法去「拉平或限制」奖励 | **灰色延续**；银行下一战在 OCC | 总览 / 银行备忘录 |
| **美国原发代币 / 现货上架 / 山寨进司库** | **是** | 与 Circle 主业弱相关 | 交易所备忘录 |
| **通证化现金作为储备** | **否** | BUIDL/BSTBL/BRSRV 仍在 | BlackRock 产品线 |

**活下来的 Circle 股权故事 = 支付网络 + 储备基金，不是「美国加密纳斯达克的配套美元」。**

### 4.1 2026 年已落地、且不靠 CLARITY 的产品

1. **CPN Managed Payments（2026-04-08）：** PSP / 银行 / 金融科技只碰法币，Circle 代管铸销、编排、合规与链。[新闻稿](https://www.circle.com/pressroom/circle-launches-cpn-managed-payments-a-full-stack-platform-for-seamless-stablecoin-settlement)。这是把 USDC 卖成 **SWIFT 替代的抽象层**，客户甚至不必持有稳定币。
2. **CPN 规模（Q2 末）：** 滚动 30 日年化量 **$147 亿**（环比 +76%），入网机构 **175**（+29% QoQ）。电话会上后提到约 **$230 亿** 年化跑率、H2 开始货币化——以公司口述为准，**尚未见独立审计拆分**。
3. **Stripe / Shopify：** Shopify Payments 原生收 USDC（Coinbase + Stripe；Base 等 EVM）；默认做法币结算。Stripe 把稳定币结算铺进 Shopify / Woo / BigCommerce 等结账。这是 **商户 TAM**，监管锚是 GENIUS 与商户收单牌照，不是 CLARITY。
4. **SAP Digital Currency Hub：** ERP 内预置 USDC（及 PYUSD）做 B2B 应付/应收。企业采用曲线继续，总览备忘录 24h 内未见上市公司因该票取消 RWA/金库项目。
5. **Arc 主网（2026-09-16，当天）：** 验证者含 BlackRock、DTCC、Visa 等；BUIDL 拟部署到 Arc。Q2 指引把 **Arc 代币预售约 $1.80 亿** 计入 2026「其他收入」（预售总额约 $2.42 亿）。这是 **高利润、一次性里程碑收入**，不能年化成支付网络，但说明产品日历没停。
6. **机构出入口：** BNY 在托管平台上开 USDC 铸销；渣打单点法币↔USDC；Nium 190+ 国家出金；JCB / Kakao / Grupo Bind 等区域试点——全部写在 [Q2 2026 新闻稿](https://www.circle.com/pressroom/circle-reports-second-quarter-2026-results)。

### 4.2 交易 TAM 为什么受伤更深

Circle 收入的 **95%** 仍是储备利息；而流通里相当一块仍坐在 **交易所与交易账户**（Q2：平台上 USDC 期末 $124 亿，日加权占比 19.5%）。CEX 奖励继续，则：

- 分销成本（Q2 分销/交易/其他成本 **$4.12 亿**）降不下来；
- 「合规、不付息的 USDC」相对「平台内 4% APY」没有立法级优势；
- 若 OCC 最终收紧 **发行人资助的第三方奖励**，资金可能迁去 DeFi 或离岸 USDT，而不是自动回流 Circle 利润率。

**没有 CLARITY：支付故事的分子还在，交易故事的分母（美国结构溢价）被拉长。** 卖方若仍用「40% 流通 CAGR + 奖励规则红利」一套模型，需要把第二项剃掉。

## 5. 国际：MiCA / 港 / 新作为对冲——能补多少

美国被劈成两半：**美元支付轨仍领先，市场结构轨外溢。** 对 Circle，国际是 **产品对冲，不是估值对冲**（上市主体仍是美国政策股）。

| 辖区 | 2026-09 状态 | 对 USDC / CRCL |
|---|---|---|
| **欧盟 MiCA** | 过渡期 2026-07-01 已结束。Circle Internet Financial Europe SAS（法国，ACPR）为 **EMI**；USDC / EURC 为已通知 **EMT**。USDT **不在** ESMA EMT 登记。约 23 家 EMT 发行人，**0 张 ART**（总览口径）。 | **不依赖 CLARITY 的最大结构优势。** 持牌所不能把 USDT 当合规 EMT 卖给 EEA 客户。支付与法币稳定币份额应继续向 USDC/EURC 倾斜。 |
| **香港** | 稳定币条例下仅 **Anchorpoint（渣打系 HKDAP）与汇丰** 两张牌。USDC **未获香港发行牌**；向公众营销未持牌法币稳定币受限。切尔西球衣赞助已在港引发零售合规摩擦。 | **不是对冲，是缺口。** 港币结算与零售通道归银行系。Circle 在港更多是机构专业投资者与跨境，不是本地零售旗。 |
| **新加坡** | 交易所已牌；稳定币框架 2026-09 仍在征询（总览）。 | 赢机构代币化与区域财资，不赢全球零售旗；对冲有限。 |
| **英国** | 全面生效 **2027-10-25** | 2026 抢不到窗口。 |
| **日本** | 2026-06 外币合规稳定币分销已通；JCB 试点 | 慢、零售保护强，但是支付叙事的正例。 |
| **阿联酋 / 离岸** | 多轨运转 | 订单簿与 USDT 仍强；对 Circle 是交易 TAM 流失，不是支付 TAM。 |

**国际能补的：** 欧盟合规美元/欧元的 **份额与品牌**；日本/拉美/韩国的银行出入口；CPN 跨境。  
**国际补不了的：** 美国银行分销的立法加速、港币零售牌、股权上的「美国政策 β」。  
**净效果：** 产品基本盘比「纯美国加密股」更宽，但 **CRCL 倍数短期仍由纽约定价**。
