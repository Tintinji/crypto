# Circle（NYSE: CRCL）短长期影响合成

**对象：** Circle Internet Group / USDC 发行人  
**事件：** 2026-09-15 参议院对 H.R. 3633（CLARITY Act）启动辩论的 cloture 以 **49–50–1** 失败（唱名第 234 号）  
**研究日期：** 2026-09-16  
**本稿性质：** 四路并行简报的决策合成（政治监管 / 传统银行 / 交易所分销 / 估值产品），对照总览 `research/2026-09-16-clarity-act-impact.md`。不是交易建议。  
**价格更新：** yfinance 2026-09-16 约 18:36 UTC，CRCL 最新 **$80.10**（9/14 收 $97.42，两日约 **−17.8%**）；COIN $163.48（两日约 −14.6%）；PYPL $52.88（约 −2.1%）；JPM $350.12（相对 9/14 基本持平）。

## 1. 一句话裁决

CLARITY 失败对 Circle **不是特许权事件，是增长期权与倍数事件**。USDC 作为美国支付稳定币的发行人合法性仍由 **GENIUS（P.L. 119-27）** 托底——1:1 储备、按面值赎回、披露、2027 许可门槛、2028 DASP 货架墙都还在。被抽走的是三样东西：**(i)** 银行级分销的成文法备忘录，**(ii)** Coinbase 式平台余额奖励的立法安全港，**(iii)** 美国现货中介法给 CRCL 的市场结构溢价。近端 P&L（储备利息 − 分成）不被这次唱名改写；真正决定 2027–2028 现金流形态的，是 **OCC 对「发行人资助第三方奖励」的终稿**、**FQPSI / 州信托过渡是否赶上 2027-01-18**，以及中期后谁主持银委会与金服委——不是 49–50 本身。

## 2. 被击中 vs 未被击中：GENIUS 特许权 vs 增长期权

必须先拆开两套法律。**GENIUS 管发行人；CLARITY 管市场结构、中介、银行分销与平台奖励。** Circle 的股权叙事把两者捆在一起卖，法律上它们不是一回事。

| | **还在（GENIUS 特许权 / 已落地产品）** | **被减记（增长期权 / 倍数）** |
|---|---|---|
| **法律身份** | 支付稳定币品类已立法；发行人不得仅因持有付息；超 $100 亿须走联邦主监管 | 国民银行 / 社区行「可以上架 USDC」的成文法没有到手；合规官选前不会为没有国会背书的零售包装签字 |
| **牌照** | OCC 国家信托（2026-07-10 终批，**该行不发币**）、NYDFS 信托（2026-07-31）、BitLicense / MTL / FinCEN MSB / 法国 ACPR MiCA EMT | 信托牌 **≠** FQPSI。联邦合格发行人规则仍是拟议稿，约 2026-11 才可能出终稿 |
| **储备引擎** | USDXX（约 $623 亿，7 日 SEC 收益约 3.60%）+ GSIB 现金；Q2 储备收入 $6.68 亿，占总收入约 95% | 下一季票息仍由浮存 × 短端利率决定，**不被这次投票取消**；被杀的是「银行司库替代」叙事 |

| **支付产品** | CPN（Q2 末 T30 年化约 $147 亿，175 家机构）、Stripe / Shopify / SAP Hub、Arc 主网（9/16，8/5 已预告，**不是对投票的反应**） | 「美国加密纳斯达克的配套美元」这条 IPO β 被拉长久期 |

**一句话分层：** 发行人合法性 intact；Coinbase 奖励经济学、银行分销、市场结构倍数 impaired。PYPL / JPM 几乎不跌、CRCL 与 COIN 近乎 1:1 同杀，已经把这个分层写进价格。

## 3. 短期（数日至数周，至 2026-11-03 中期）

立法窗在实质关闭：参议院约 10/5–11/6 州工作期，Tillis 复议是技术保险不是政治动能。本会期再凑 60 票的概率低。Circle 的「国会故事」结束了，「实施故事」进入评论期高潮。

### 3.1 政治

伦理 / 特朗普家族加密利益是 CLARITY 的**政治死因**，不是 Circle 的产品死因。Circle 在牌照史上是持牌金融科技（2015 BitLicense、2024 MiCA、2025 上市），不是总统家族控股实体；民主党主靶是 WLF / USD1，不是 USDC。但 2026 秋存在**误捆风险**：OCC「加密信托牌」听证可能把 Circle National Trust 与 World Liberty 附条件批准放在同一张图上，镜头不区分法律地位。州 AG 不需要新联邦法就能用消费者法打「平台奖励是否误导为存款」。选前真正的硬日历是 **10/19 财政部 §3 NPRM 评论截止、10/20 SEC Reg Crypto 评论截止、约 11 月 OCC GENIUS 实施终稿、11/3 中期**。

### 3.2 银行

银行在院外与股权叙事上**战术赢了**：挡住平台奖励成文法安全港，弱熔断也没入法；JPM 投票日几乎不动。法律上他们**不是新赢家**——投票没有让平台奖励变得更违法，也没有给银行一条事前禁令。分销要拆三条曲线，不要写成「银行集体退出 USDC」：托管 / 铸赎 / CPN **继续**（BNY、渣打、Nium 是手续费，不是核心存款替代）；社区 / 区域行「核心存款 + 支付」零售包装 **会慢**；通证化银行存款建设 **不受阻**（它们本来就不靠 CLARITY）。社区行怕的零售活期外流仍是政治主张，9/15 后未见新的周度 FDIC 数据结算这场争论。

### 3.3 交易所

未发现任何 CEX 因该票停掉 USDC rewards 或解除 Circle 分销协议。Coinbase 激励仍是继续推 USDC：平台内每 1 美元，储备收益全部留在 COIN（Q2 稳定币收入 $292M，平台内季均约 $20B）。基线是奖励**不会因唱名下线**，但会「律师化 / 任务化」——从纯 APY 滑向交易量、支付、订阅捆绑；Kraken 自费忠诚（1.75% / Kraken+ 3.75%）比发行人资助模式更可辩护。Circle 2026 年内改不了婚姻：排除条款有 60–90 天补救 + 最长 12 个月尾款。增量预算的理性方向是已经能签约的 **CPN / 国际 CASP / Arc**，不是再找一个美国 Coinbase。约束：CPN $147 亿年化相对链上 $14.8T、相对 Coinbase $20B 余额仍是小数。

### 3.4 股票 / 产品

CRCL 近 21 日与 COIN 相关约 **0.94**、3 个月 β 约 **0.99**，短端仍是高 β 交易所影子，不是独立支付股。9/14 $97 附近买的是「残值市场结构标题」；现价 $80.10 贴近 / 略低于 200 日均线（约 $85.7），尚未打到 50 日（约 $75.4）的更干净基本面底。卖方目标均值仍约 $104，前瞻 P/E 约 53x。宏观分裂值得单独标：市场定价 FOMC 加息 25bp 对 BTC/COIN 倍数是逆风，对 Circle **下一季储备收入是顺风**（流通 $742 亿上，+25bp 约 +$1.86 亿毛储备利息，未扣分成）。9/15–16 股权账户用「加密政策股」因子交易，还没用「短期利率收取人」因子。USDC 供给走平 / 微降（数亿美元级，<1%），不是赎回事件。

## 4. 长期（2027–2028+）

硬日期是 **2027-01-18（发行人许可）** 与 **2028-07-18（DASP 分销墙）**，不是 2026-09-15。CLARITY 失败拿掉的是美国银行分销的**可选加速**，没有拆掉特许权墙。

### 4.1 政治

2027 基准是分裂国会（政治简报约 45–55%）：GENIUS **不会被废**（废法要两院 + 总统，特朗普仍在）；CLARITY **不会轻易复活**（需银委会 + 农业委四委员会协调）。立法冻结对已在 GENIUS 轨道上的 Circle 是相对保护——新来者更难要新法豁免，合规沉没成本变成壁垒。若 Warren 主持银委会：主风险是把 OCC 奖励推定写成「直接或间接」全面禁止、把 FQPSI 审批拖进「无终稿、有法定日」夹缝，以及把 Circle 信托与 WLF 打包听证；她要的是更像银行，不是把 Circle 赶出美国。若 Waters 主持金服委：框架与 Circle 产品形态并不相反（非银行发行人 + 严储备 + 反科技巨头控股）；主敌是总统家族币与「联邦抓手不够」的文本，Circle 会被要求划清界限，并按上市公司标准准备分成 / 双轨披露。可逆的是实施松紧，不可逆的是「美国要许可发行人」这条制定法。

### 4.2 银行

2027–28 Circle 相对银行的位置由三件事决定，而不是由 9/15 唱名决定：(1) OCC 终稿对「相关第三方」奖励的硬度；(2) TCH 是否在 2027 真正跨行；(3) 中期后国会控制权。企业司库基准是**互补大于替代**：USDC 吃公链、任意地址、跨境与代理支付；JPMD / CTS / BNY 镜像吃可付息、白名单、TMS / SWIFT 与盘中保证金。真正的存量争夺发生在大企业把闲置美元从 USDC / 代币化货基挪回可计息的银行负债，以及 TCH 若打通跨行之后。21 家机构合资稳定币目标 2027H1——**现在不存在**，成立 ≠ 发币。没有 CLARITY 交易，社区行难以大规模代销 USDC；巨型行双轨：卖自己的存款代币 + 有选择地托管 / 清算 USDC。

### 4.3 交易所

2028 年美国人在持牌 DASP 上能买的支付稳定币，短名单大概率是 **USDC、PYUSD、合格银行稳定币、USAT（若 Anchorage 路径站稳）、或许 RLUSD / USD1（若 PPSI 落袋）**。USDT 全球币（约 $1833 亿）继续统治离岸深度，但美国零售货架出局或迁到 USAT（现仅约 $1.8–1.9 亿，是 USDC 的 ~1/400）。Circle 赢的是**合规货架**，不是自动赢流通。更可能的稳态是「货架赢了，美国现货活动没做大」：供给稳住、美国 CEX 交易份额不涨、离岸报价继续偏 USDT。2029 再谈判 Coinbase 分成时，Circle 的筹码取决于自有平台（Q2 末 $12.4B）/ CPN / Arc 是否已替代一部分 $20B。OCC 若咬死发行人资助的余额 APY，受伤顺序是 Coinbase 零售奖励 → 平台内余额 → Circle 流通与叙事；分销合同成本不会同比例下降，资金更可能去 DeFi、代币化货基或离岸 USDT，而不是社区银行活期。

### 4.4 股票 / 产品

长端股权故事若还能支撑成长股倍数，只能靠 **支付网络 + 储备基金 + 2028 货架墙**，不能再靠「美国现货中介法配套美元」。国际是**产品对冲，不是估值对冲**：欧盟 MiCA 下 USDC/EURC 是已通知 EMT、USDT 不在牌内——这是不依赖 CLARITY 的最大结构优势；香港两张稳定币牌给了银行系（Anchorpoint / 汇丰），USDC 未获港发行牌，是缺口不是对冲；CRCL 倍数短期仍由纽约定价。偏牛（约 25%）：OCC 收紧平台奖励 + USAT 起不来 + CPN/Arc 把其他收入做实，倍数从「纯基金」回到「基金+网络」。偏熊（约 25%）：2027 实施被拧紧或延误、银行币 + 通证化现金切走储备外余额、供给跌破 $60B，特许权变成高 β 货币市场基金，FY27 约 58x 站不住。基准（约 50%）：USDC 保持「美国合规美元」第一，供给 CAGR 低于公司口头 40%，支付 + 机构仍能支撑网络叙事。

## 7. 置信度与四份简报的残留分歧

### 7.1 四路一致（高置信，可当工作假设）

- 唱名 **49–50–1**，程序性失败不是最终否决；民主党赞成票为 0；GENIUS **未被废**。
- 被杀的是银行分销 + 中介法 + 奖励安全港的**增长期权**，不是 USDC 发行人特许权，也不是下一季 T-bill 票息。
- 平台奖励在成文法上**既没有被新禁，也没有得到安全港**；下一件真武器是 OCC 可反驳推定，不是这次唱名。
- Circle–Coinbase 分成续约至 2029，近端改不了；9/15–16 未发现停奖或解约公告。
- 支付轨道（Stripe / Shopify / CPN / Arc）不依赖 CLARITY；Arc 9/16 主网是 Q2 已预告日程。

### 7.3 机制判断分歧（中 / 中低置信，保留分叉）

1. **OCC 收紧对 Circle 净利润是好是坏。** 政治与银行简报强调不对称：奖励被砍 → 平台内余额可能降，分销成本也降，Circle 的 cons 本就不是「最高收益」。交易所与估值简报更悲观：合同锁到 2029，成本不会同比例下降；资金更可能去 DeFi / 离岸 USDT / 代币化货基，不是回流 RLDC。**本稿立场：** 流通与叙事受损是基线；利润率改善只在「分成对象主动减奖 + 自有平台占比上升」时成立，不能当成自动对冲。
2. **支付能否补上 CEX 交易 β。** 估值简报把支付网络当作无 CLARITY 时唯一能支撑溢价的成长故事；交易所简报强调 CPN $147 亿年化相对 $20B Coinbase 余额和 $14.8T 链上量仍是小数。**本稿立场：** 支付是正确的战略方向盘，不是 2026–27 的 P&L 替代；近端收入仍是储备收益减去分成。
3. **OCC 终稿是否咬死现行分成。** 四路都标「文本瞄得上、终稿未出」。政治标中；交易所标中低。反驳空间取决于终稿如何定义 *pay*、*interest or yield*、*solely*、*related third party*。Circle CEO 对 OCC 提案公开偏正面、与 Coinbase 激励不完全一致——发行人要牌照确定性，交易所要奖励漏斗。
4. **2028 墙是否必然清掉 USDT 美国货架。** 法律日程已写死；估值简报标中，因为财政部同等性认定与「位于美国」定义仍可被划窄。政治简报的 Circle 输家条件正是这条豁免。
5. **USAT 能否忽略。** 今天 $1.8–1.9 亿可忽略（高置信）；估值简报把「长期可忽略」标中低——Tether 分销一旦打开会非线性。交易所简报用「有牌 ≠ 有分销」解释 8 个月没做大。
6. **Arc 对 2027 特许权的贡献。** 估值标低（主网日使用数据为零）；交易所标日程高、是否加速为中。**不要把 9/16 上线写成对投票的战略转向。**
7. **2027 国会控制权。** 四路都标中低。政治给出分裂 45–55%、Warren 条件于参议院翻转约 25–35%、Waters 金服委概率高于参议院翻转。总览与政治一致：立法接近冰冻，行政机关是主渠道。
8. **被抽走的期权价值。** 估值简报量化为约 15–20% 市值 / 约 $43 亿（相对 9/14），标中高，不是回归。新鲜价格把这段略扩到约 −18%。精确拆分政策 vs FOMC 不是四路已做的工作。
