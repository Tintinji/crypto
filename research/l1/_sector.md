# 赛道：智能合约 L1

快照：`2026-09-16T21:13:43Z`。21 个标的，合计 MC **$419.0B**。逻辑链 **A**。BNB/CRO 的价值捕获更偏交易所，已划出本赛道。

## 需求从哪来

L1 卖的是 **区块空间 + 状态承诺 + 生态 gravitas**。付钱的是：

- 终端用户与机器人付 gas（链费用）
- 应用把流动性与用户锁在这条状态机上（TVL、稳定币存量、日活）
- 质押者把代币锁成安全预算

代币能不能留下这些钱，取决于：费用是否销毁/分给持有人、通胀是否对冲费用、以及应用层是否把价值留在自己的 token。

读法：

- **ETH**：应用与稳定币仍在，但 L1 执行费被 rollup 抽走。$208M 年化费用对 $294B 市值意味着市场买的是结算层 + 抵押品货币，不是 L1 gas 现金流。
- **SOL**：费用年化 $241M，高于 ETH L1，市值只有 ETH 的约 1/5。市场用「高吞吐应用链」定价，不是用结算货币溢价。
- **TRX**：费用年化 $356M，主要来自稳定币转账。这是支付轨道 L1，不是通用计算溢价。
- **Canton (CC)**：机构隐私 L1，链费用 30d 高达 $49.6M（Llama 链费用榜前列）。必须单独核对其费用口径是不是内部流量计价，不能直接当「比 ETH 更赚钱」。

## 估值锚

1. FDV / 年化链费用：ETH 四位数，SOL 数百倍，TRX 更低。差异来自货币溢价，不是会计错误。
2. MC/TVL：ETH 6x、SOL 10x 是「有生态」的区间；TVL <$1B 还要 $3B+ 市值的链，默认当作叙事溢价。
3. 相对 BTC：ETH 1y **-46.4%**（相对 BTC **-17.8%**）；SOL 用该币 facts。周期上 L1 贝塔大于 BTC。

## 拥挤点

- 通用计算过剩：SUI / AVAX / NEAR / ADA / DOT / INJ 抢同一类开发者，用户迁移成本在下降（跨链桥、意图层）。
- 费用向 L2 与应用链泄漏：ETH 是主受损方，也是主受益于「结算货币」叙事的一方。
- 机构链（Canton）与消费链（GRAM/TON）不是同一市场，禁止把它们和 ETH 放进同一张倍数表就下「贵/便宜」结论。

## 单币写作要求

先声明该 L1 卖的是结算货币、高吞吐执行、支付轨道还是机构隐私，再用对应锚。不要每篇都重写「区块链是什么」。
