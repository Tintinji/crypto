## 4. 多空交锋后的净判断

按 `03-debate.md` 第 2 轮六点裁定，不复述多空原文。

1. **三十日跑输/一年横盘＝费用空转：反驳，并降级空方措辞。** 「需求叙事空转」须降级为「价格重定价，费用与 TVL 仍在」。多方同时承认：**$355.61M** / **$5.40B** / **5.91x** 只证明用量未消失，不证明需求在扩张；30d **+1.40%** / 相对 **-14.43%**、1y **-1.90%** 双方承认。不得把未知稳定币流通补成份额成长。
2. **未知收入＝捕获为零：承认空方缺收入，反驳其充分条件。** 双方承认协议收入未知，**89.67x** 分母是链费用不是持有人收费权。空方「捕获为零」降级为「捕获不可核验」；多方不得把未知销毁/分红补成捕获已成立。
3. **支付轨易迁＝费用将走：降级。** 双方承认支付轨迁移成本低于结算位，Canton 不得并表。空方「稳定币将换轨」降级为未观测迁出；多方「**$5.40B** + **$24.53M**/30d 搬迁成本极高」同样缺迁出序列，降级为存量费用，不是不可替代证明。
4. **低倍数＝轨道已便宜：承认多方循环。** 稳定币流通与协议收入未知，**89.67x** 不能自证便宜；低于 ETH/SOL 是溢价读法。空方承认按支付轨尺子倍数低于通用计算（赛道原话），但不能把 **-22.13%** / **-1.90%** 写成溢价已归零。
5. **一年少跌＝需求扩张：承认多方超证。** 1y **-1.90%** / 相对 **+50.46%** 是少跌，30d 相对 **-14.43%** 可逆，**$433.92M** / **1.36%** 是薄换手。空方不得因短窗跑输与稳定币流通未知就主张 **$355.61M** 已失效。
6. **全流通＝供给安全 / TVL＝迁移成本：双方都缺锚。** 最大供给、解锁、协议家族 TVL、CEX AUM 未知。多方「无未解锁抛压」只排除库存折价；空方「看不见日历即供给变差」是数据缺口，不得编造到期美元。**$5.40B** 是锁仓，不是已观测搬迁账单。ATL **$0.001804** 只作历史下沿。

净判断：支付轨道对费用领先的对打已落地——年化 **$355.61M** 与 TVL **$5.40B** 仍在是事实；协议收入与稳定币流通不可核验，也是事实。第 1 条空方败在用价格路径否定已核对费用；第 2 条空方败在把未知补成零捕获；第 4、5 条多方败在循环论证与少跌超证。第 3、6 条仍开放：迁出未观测但迁移成本也未核验，供给与净发行双方都缺锚。可验证的是链费用、锁仓与低费用倍数；不可验证的是稳定币份额、协议收入、销毁/分红与供给硬顶。主风险不是「费用已空」，而是轨道论无法被稳定币存量证伪，同时捕获通道停在链费用口径。周期上 L1 贝塔大于比特币。仍开放：费用若塌到长尾 L1 量级，市场会否改按通用计算尺子给 **$31.89B** 定价。

## 6. 什么会让结论反转

1. **费用或 TVL 可观察塌陷。** 链费用 30d 相对 **$24.53M**、年化相对 **$355.61M** 持续收缩至长尾 L1 量级，或 TVL 离开 **$5.40B** 使 MC/TVL 脱离「有生态」的 **5.91x**，则「价格重定价、费用与锁仓仍在」不再成立。
2. **定价锚切换。** 市值按通用计算或结算货币尺子重估 **$31.89B**；或反过来，协议收入从未知变为可引用且能对上 **89.67x**。前者证伪支付轨费用定价，后者改写「捕获不可核验」。
3. **未知项变为可核验。** Llama 稳定币流通、已验证净发行或 30/90 日迁出对照出现：若稳定币存量对不上年化 **$355.61M**，或最大供给未知下出现可测增发，则轨道论升级为份额缺口或供给冲击；若出现迁出序列，则「存量费用≠不可替代」被证伪或坐实。
