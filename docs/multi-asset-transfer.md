# 同一套因子模型能否推广到其他主流币？

研究笔记，**不是投资建议**。十个币各自在隔离工作树里用同一套 `factorlib`（PIT z-score、15 bp、`signal_lag=1`、排除 fixture 后筛选）对准该币次日收益。窗口均为 **2023-01-01 → 2026-09-16**。买入持有只扣首日 15 bp。筛选组合用了「OOS 同号」门，**全样本 Sharpe 不是干净样本外**。

总判定：**工程能推广，策略不能原样推广。** 十个币全部是「部分能推广」。没有一个币支持「把 BTC 默认叙事权重换 ticker 就当 alpha」。

## 2. 三类币，三种「跑赢」幻觉

### A. 赢家币：ETH / SOL / XRP / BNB / LINK

现货本身是正溢价。所有 z-score 组合（tanh ±1）都 **跑不赢买入持有**。默认映射偶尔小正（SOL 0.67、XRP 0.72），是偏多权重坐上了高 beta 牛市，不是残差 alpha。

- **ETH**：对 BTC R² 0.67，残差为负。这段没有「ETH = BTC + 独立 alpha」。
- **SOL**：唯一现货大幅跑赢 BTC（约 9.8×）。突破腿对 BTC 残差仍有 IC；默认 22 条只活 4 条。
- **XRP**：法律/叙事跳空大（2023-07-13 单日约 +73%）。筛选配方跨币种失败（筛选 Sharpe −0.38）。Yahoo「韩溢价」测不到 Upbit。
- **BNB**：β≈0.73，交易所代币残差弱。筛选无增益。
- **LINK**：高 beta 基础设施；对冲 BTC 后残差没有正溢价。默认趋势映射 Sharpe −0.17。

### B. 落后 / 崩盘币：ADA / AVAX / LTC / DOT / DOGE

组合「跑赢持有」几乎都等于 **没扛满下跌**（净空或低暴露），不是因子更准。

- **DOT** 默认仓位约 67% 日子为负；2025 筛选组合大涨，同期 DOT −73%。
- **AVAX** 持有回撤约 −90%；默认「赢」是没扛 boom-bust。
- **LTC** 默认周期多头 Sharpe −0.62，比持有更亏。
- **ADA** 没有日频「BTC 先动、ADA 后跟」。
- **DOGE** 特质波动约 57%（占总方差 46%）；宏观袖子单独亏损。

## 3. 什么能带走，什么带不走

| 层 | 结论 |
|---|---|
| 价量模板 + PIT 筛选 CLI | **能。** 十个币都跑通 `px_{asset}_*`。 |
| DXY（美元↑ → 次日风险资产↓） | **最能平移。** ETH/SOL/XRP/ADA/AVAX/LINK/DOGE 均同号入选或方向一致。 |
| 油价簇 | **部分。** 多币 IS 为负；LTC/ADA 等 OOS 翻号。与 WTI/Brent 相关 >0.98，只留一条。 |
| 10Y 变动 | **不能当通用次日因子。** SOL 入选但符号与默认相反；ETH/BNB/ADA 过不了门。 |
| 200/365 日均线、动量 20/60 | **几乎处处 OOS 翻号或与 RSI/VPT 共线（ρ>0.8）。** 周期位置跨币共线（BTC 与 SOL 200dma ρ≈0.83）。 |
| ICIR + OOS 同号筛选配方 | **不能当可迁移 alpha。** XRP 上筛选明显劣于默认；多币严筛后优势消失。 |
| 「换 ticker 复用 BTC 默认权重」 | **不能。** 十票全否。 |
| 韩国溢价 / ETF 流 / FOMC 旗标 | **当前数据不能交易。** 仍是 fixture 或 Yahoo 交叉盘残差。 |

先拆 BTC beta，再谈「换币后因子还在不在」。ETH/LINK 上宏观 IC 去掉 BTC 后明显变弱；SOL 突破、油价残差 IC 掉得少。

## 4. 若要做成多币生产流程

1. **预注册按币种假设**（ETH：高 β + DXY；SOL：突破残差；XRP：法律跳空；DOGE：特质波动），不要 70–100 列里捞 ICIR。
2. **标签用 5d/20d 和波动调整收益**，不要只报次日 IC。
3. **对 BTC 做残差或中性化** 后再筛选；否则入选的多是共同因子。
4. **相关簇按一条代表计一次检验**（油、均线、VPT）。
5. **冻结规则后用新时间验证**；禁止把筛选组合的全样本 Sharpe 当 OOS。
6. **fixture 进实盘前必须换成真源**（Farside ETF、官方日历、真实韩国溢价）。
7. 落后币上「策略跑赢 BH」要拆成：是空了崩盘，还是真有预测力。

复现各自隔离树（示例）：

```bash
cd /tmp/factor-ETH
PYTHONPATH=/tmp/factor-ETH/src python3 -m factorlib --config config/eth.yaml ingest
PYTHONPATH=/tmp/factor-ETH/src python3 -m factorlib --config config/eth.yaml screen-factors
```

研究工具。加密波动极大，可能损失全部本金。
